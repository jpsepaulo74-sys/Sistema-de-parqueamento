# Sistema-de-parqueamento

Este repositório contém uma aplicação frontend simples de gestão de parqueamento.

Estrutura (essencial):

- `index.html` - página principal (HTML)
- `css/style.css` - estilos
- `javascript/app.js` - lógica em JavaScript
- `minimal-entry/` - demo reduzida com apenas formulário de entrada (HTML/CSS/JS)

Como executar (servidor estático):

1. Abra uma shell no directório do projecto.
2. Execute:

```bash
python3 -m http.server 8000
```

3. Abra no navegador: http://localhost:8000

Observações:
- O projecto é inteiramente cliente (HTML/CSS/JS). Não há backend.
- Existe uma cópia antiga/duplicada dentro da pasta `Sistema de Parqueamento/`. Se quiser remover essa cópia manualmente, use:

```bash
rm -rf "Sistema de Parqueamento"
```
